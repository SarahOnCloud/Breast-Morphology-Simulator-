# Breast-Morphology-Simulator-
this project was me and my friend Julie Nguyen's Submission to the 2026 National Canadian Medical Datathon.
Our data was originally sourced from The Breast Cancer Wisconsin (Diagnostic) Data Set, curated by researchers at the University of Wisconsin Hospitals. 
currently this project include the code we used to make the main graph for our submission, a youtube link to our project overview and a link to the data source.
